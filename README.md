# Number-Translate

### NumTranslate  - это Windows Forms приложение для перевода чисел между различными системами счисления. Программа поддерживает:

- Перевод между стандартными системами счисления (2-16)
- Поддержку пользовательских систем счисления (до 36)
- Ввод и вывод чисел с дробной частью
- Проверку корректности введенных данных
- Интерактивного помощника (Clippy)

### Основные возможности:

Ввод числа:
Поддержка целых и дробных чисел
Автоматическая проверка на соответствие выбранной системе счисления

Выбор систем счисления: Стандартные системы: двоичная, троичная, восьмеричная, десятичная, шестнадцатеричная
	Пользовательские системы (от 2 до 36)

Перевод чисел:
	Точный перевод между любыми поддерживаемыми системами
	Округление дробной части до 4 знаков

Интерактивный помощник:
	Анимированный Clippy
	Контекстные подсказки
	Визуальная обратная связь


Использование:
	Введите число в верхнее поле ввода
	Выберите исходную систему счисления (из списка или укажите свою)
	Выберите целевую систему счисления
	Нажмите кнопку "Перевести"
	Результат отобразится в нижнем поле
	Особенности реализации

Технические детали
Библиотека перевода: TranslationOfNumberSystemsClassLibrary

Основные алгоритмы:
	Проверка символов на соответствие системе счисления
	Перевод целой и дробной частей числа
	Округление результатов
	Пользовательский интерфейс:
	Динамическое создание элементов управления
	Адаптивная компоновка
	Анимации и визуальные эффекты
